## 📌 Problem Statement

Electronics and Telecommunication Engineering combines electronics, communication systems, embedded technology, signal processing, and Artificial Intelligence. Learning these topics through theory alone is difficult.

**Challenge:** Develop an interactive, user-friendly web prototype that makes ENTC learning practical and engaging, bridging theoretical concepts with hands-on experimentation through AI-powered learning.

---

## 💡 Our Solution

The Smart ENTC Learning & Innovation Platform combines structured learning, browser-based simulations, coding challenges, quizzes, and real-world scenarios in one place, with an AI assistant guiding learners at every step.

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 📚 **Interactive Learning** | Simplified lessons on digital electronics, communication systems, sensors, microcontrollers, and signal processing |
| 🔬 **Virtual Electronics Lab** | Browser-based simulations of basic circuits, logic gates, and sensor-based systems |
| 🤖 **AI Learning Assistant** | Explains concepts, helps troubleshoot errors, and answers technical questions |
| 💻 **Coding Challenges** | Logic-building and Arduino-style programming exercises |
| 🎮 **Quizzes & Mini-Games** | Circuit puzzles, component identification, logic challenges, and timed quizzes |
| 🏠 **Real-World Simulations** | Smart home automation, IoT monitoring, sensor-based safety systems, intelligent communication networks |
| 📈 **Progress Tracking** | Track completed activities, quiz scores, and overall learning progress |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, Safari)
- Git (optional, for cloning)

### Installation

```bash
# Clone the repository
git clone https://github.com/SmileofHaven/chakravyuh-Supernova-T119.git

# Move into the project folder
cd chakravyuh-Supernova-T119

# Open the platform
# Option 1: open index.html directly in your browser
# Option 2: run a local server
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
